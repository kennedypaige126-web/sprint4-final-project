# sprint4-final-project

Sprint 4 Final Project: E-Commerce Customer Behavior EDA

Project Overview
This project analyzes customer purchasing behavior, product performance, order fulfillment, and customer satisfation using the Olist Brazilian E-Commerce dataset. Through exploatory data analysis (EDA), the project identifies trends in sales, delivery performance, customer locations, and product category success to generate business insights and recommendations for imporving operational efficiency and customer experience.

Dataset
The analysis uses the Olist Brazilian E-Commerce Data set, which contains information on nearly 100,000 orders placed between 2016 and 2018. The dataset includes customer information, oderdetails, product categories, payments, reviews, and every delivery data.
Files Used include:
- Orders Dataset
- Order Items Dataset
- Customers Dataset
- Products Dataset
- Product Category Translation Dataset
- Order Reviews Dataset
- Order Payments Dataset

Tools and Libraries
This project was completed using:
- Python - Data anaylsis and data manipulation
- Pandas - Data cleaning, transformation, and analsis
- Matplotlib - Data visualization and trend analysis
- Jupyter Notebook - Interactive analysis and reporting
- Git & GitHub - Version control and project management

Key Analysis Areas
- Order status and business performance
- Monthly order trends over time
- Revenue by product category
- Customer review score analysis
- Customer geographic distribution
- Delivery performance and shipping times
- Business recommendations based on data insights

Objective
The goal of this project is to apply exploratory data analysis techniques to uncover actionable insights that can help an e-commerce business customer satisfaction, optimize operations, and increase revenue growth.
